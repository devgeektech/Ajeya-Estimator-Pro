STEP 1 — UNDERSTAND THE SECTION (read everything before extracting):
- ``description`` / ``lineage_lines`` tell you WHAT SYSTEM this section covers
  (e.g. "Yard Hydrant System", "Sprinkler System for Basement").

- ``slots`` are the individual rows with Quantity + Unit — these are the ONLY
  source of products. Read every slot's description AND unit together.
- Spec-only lines (Speed, Head, Pressure, IS standard, notes) are shared

STEP 2 — CLASSIFY EACH SLOT (product vs. non-product):
For each slot, ask: "Is this a PHYSICAL ITEM that can be purchased/procured?"

Extract as PRODUCT when the slot describes:
- Equipment: pumps, valves, sprinklers, extinguishers, tanks, gauges, panels
- Materials: pipes, fittings, hose reels, hose boxes, branch pipes, cables
- Hardware: hydrants, nozzles, expansion joints, rosette plates

Mark as NON-PRODUCT (``skip_matching: true``, ``products: []``) when:
- The row describes WORK/LABOUR/ACTIVITY, not a thing to buy.
- Unit is "Job" / "LS" / "Lump Sum" / "Lot" AND description is an activity.
- Description talks about: testing, commissioning, dismantling, removing,
  refixing, painting, site preparation, shop drawings, hydraulic calculations,
  approvals, documentation, as-built drawings, insurance, transportation, making connections, etc.
- IMPORTANT: Even if the row has a quantity (like 1) and unit (like NOS, Set), if the description is primarily about a job/activity (like "installation of..."), MARK AS NON-PRODUCT. Do not extract the item being worked on as a product if this is just an installation line.

from the DATABASE_CONTEXT, set ``skip_matching: true``.
